# Owner-directed report simplification

Remove manual assumptions, BRRRR, sensitivity and calculation-basis controls from
the expanded report. No calculator module is loaded or mounted by report.html.
Existing calculator code and previously saved assumptions are not deleted.

Section 4 now shows a compact factual overview: geography, regional income/rent
estimates with published margins of error, and the parcel's verified school
district. Detailed Census tables, school performance and official source links
remain inside a closed disclosure. Printing does not automatically expand this
area disclosure; the user may open it explicitly before printing.

Owner explicitly chose external-source ratings only, otherwise a short summary
without a grade. No A–D score, proxy completeness grade or inferred neighborhood
quality is calculated. Current sources do not supply a verified overall grade.
