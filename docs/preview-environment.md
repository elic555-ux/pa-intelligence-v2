# סביבת בדיקה מבודדת

הסביבה נמצאת ב־`/preview/` ומציגה את גרסת הפיתוח 8.21.5. גרסת המערכת הפעילה נשארת 8.21.3.

היא מציגה שלושה נכסים לדוגמה, פרטים ותמונות מעותקי מקור ציבוריים שמורים, חדר עסקאות ודוח. נתוני הניסוי נשמרים בדפדפן תחת מרחב שמות נפרד. הם אינם מועתקים מטבלאות חדר העסקאות הפעיל.

יש סימון קבוע בכל מסך. אין צורך בכניסה או במפתחות. פעולות שרת, סריקות ושליחת התראות כבויות; RentCast כבוי. לחצני שמירה בחדר העסקאות ובדוח פועלים על הנתונים המקומיים בלבד. המפה ושירותי רשת חיצוניים אינם חלק מבדיקת האיסוף בסביבה זו.

הקוד נבנה מאותו מקור פיתוח, בגרסה `aa0e03abec15e148722b5d07cf78ce1409ebd54a`. חיבור Supabase מוסר מהקבצים שנבנו ומוחלף במתאם מקומי. מדיניות הדפדפן מתירה חיבורי נתונים רק לאתר הבדיקה. קריאות GitHub לקריאת קובצי נתונים מנותבות לעותקי הדוגמה; פעולות כתיבה נחסמות. מפתחות ונתונים של האתר הפעיל אינם נקראים ממרחב השמירה שלו.

הסביבה היא כלי לבדיקת הממשק ופעולות מקומיות. בדיקות מנוע הסריקה החינמית מבוצעות בנפרד בענף הפיתוח; 219 בדיקות Python ו־32 בדיקות תצוגת מקורות עברו עבור השינוי הנוכחי. היא אינה מפעילה סריקה אמיתית או מאמתת נתוני השקעה.

כדי לעדכן: מעדכנים את `tools/preview/manifest.json` לגרסת המקור, עושים checkout לגרסת הפיתוח, ומפעילים `python tools/preview/build.py --source /path/to/source --output preview`. מריצים את בדיקות הסביבה לפני פרסום הקבצים שנבנו. בדיקת הסביבה קוראת את מזהה גרסת המקור מה־manifest. אין לערוך ידנית את קובצי הממשק שנבנו ב־`preview/`.

ניקוי נתוני הניסוי באמצעות הכפתור שבסימון העליון מוחק רק נתונים ששייכים לסביבה זו. נתוני המערכת הפעילה נשארים במרחב השמירה שלהם.
