# סביבת בדיקה מבודדת

הסביבה נמצאת ב־`/preview/` ומציגה את גרסת הפיתוח 8.21.5. גרסת המערכת הפעילה נשארת 8.21.3.

היא מציגה שלושה נכסים לדוגמה, פרטים ותמונות מעותקי מקור ציבוריים שמורים, חדר עסקאות ודוח. נתוני הניסוי נשמרים בדפדפן תחת מרחב שמות נפרד. הם אינם מועתקים מטבלאות חדר העסקאות הפעיל.

יש סימון קבוע בכל מסך. אין צורך בכניסה או במפתחות. פעולות שרת, סריקות ושליחת התראות כבויות; RentCast כבוי. לחצני שמירה בחדר העסקאות ובדוח פועלים על הנתונים המקומיים בלבד. המפה ושירותי רשת חיצוניים אינם חלק מבדיקת האיסוף בסביבה זו.

הקוד נבנה מאותו מקור פיתוח, בגרסה `b94e1ad7ea930077027c6e62b98eb384c4e45933`. חיבור Supabase מוסר מהקבצים שנבנו ומוחלף במתאם מקומי. מדיניות הדפדפן מתירה חיבורי נתונים רק לאתר הבדיקה. קריאות GitHub לקריאת קובצי נתונים מנותבות לעותקי הדוגמה; פעולות כתיבה נחסמות. מפתחות ונתונים של האתר הפעיל אינם נקראים ממרחב השמירה שלו.

הסביבה היא כלי לבדיקת הממשק ופעולות מקומיות. בדיקות מנוע הסריקה החינמית מבוצעות בנפרד בענף הפיתוח; 280 בדיקות Python, 43 בדיקות תצוגת מקורות ו־7 בדיקות הגדרות השלמה עברו עבור השינוי הנוכחי. היא אינה מפעילה סריקה אמיתית או מאמתת נתוני השקעה.

כדי לעדכן: מעדכנים את `tools/preview/manifest.json` לגרסת המקור, עושים checkout לגרסת הפיתוח, ומפעילים `python tools/preview/build.py --source /path/to/source --output preview`. מריצים את בדיקות הסביבה לפני פרסום הקבצים שנבנו. בדיקת הסביבה קוראת את מזהה גרסת המקור מה־manifest. אין לערוך ידנית את קובצי הממשק שנבנו ב־`preview/`.

ניקוי נתוני הניסוי באמצעות הכפתור שבסימון העליון מוחק רק נתונים ששייכים לסביבה זו. נתוני המערכת הפעילה נשארים במרחב השמירה שלהם.

בגרסת הבדיקה 8.21.5 הוסרו מסנן האסטרטגיה ושדה האסטרטגיה בפרטי הנכס. שטח מגורים מופיע בעמודה נפרדת ובכרטיסים, ושטח המגרש מופיע בראש פרטי הנכס עם יחידת המקור. רשומת 10 Test Ln מסומנת כנכס מומצא לבדיקת מפרט חסר; היא אינה מודעה אמיתית נוספת במיקוד 15235. הפרטים של 9242 Valley St נשענים על עותק Tarasa השמור.

עדכון 14.10.2026: שורת כיסוי מפרט ותמונות מציגה רק פרטים שנאספו עם מקור. רשומת 10 Test Ln כוללת קבלת ניסיון כושל מומצאת, מסומנת במפורש, כדי להדגים עצירה אחרי שני ניסיונות השלמה והמשך הסריקה. זו הדמיית ממשק בלבד; לא נעשו ניסיונות איסוף עבור הנכס המומצא. עותקי המקור האמיתיים ששימשו לדוגמאות נשארים ללא שינוי.

הגדרות הדוגמה מציגות קבוצה של 3 ותדירות של רבע שעה, אך השלמה וסריקה נשארות כבויות בסביבה זו. עדכון זה אינו מפעיל את הסורק בענף main ואינו ממזג את PR #2. קובצי התצוגה מפנים לסקריפטים עם תג גרסת המקור כדי למנוע הצגת עותק ישן מהמטמון.

בדיקת Preview Environment Validation בונה מחדש מהמקור המקובע, משווה את כל הקבצים שנבנו, בודקת בידוד אחסון וקריאות רשת, ובודקת את המסכים ב־Chromium עם חסימת פניות חיצוניות. היא משתמשת בהרשאת קריאה וברץ GitHub Actions רגיל, ולא מפעילה סריקות או שירותים בתשלום.
