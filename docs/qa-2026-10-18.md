## שיפור יעילות והמשך הכיסוי

פתיחת 14 נכסים שונים יצרה 84 קריאות GitHub REST מדומות, בנוסף לשתיים באתחול. `readBasicSourceJson` ב־`index.html` ו־`load` ב־`secondary_sources.js` מנסים את GitHub API לפני קובצי האתר. לפי התיעוד הרשמי, בקשות ללא אימות מוגבלות ל־60 לשעה לכתובת IP: [GitHub REST limits](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api), נבדק ב־18.10.2026.

בניסוי מקומי GitHub החזיר 403 לאחר שתי הקריאות הראשונות. הלוח נשאר פעיל, ונטענו שלושה קישורי תמונות שמורים של 812 Prospect St דרך קובצי האתר. בדיקה נפרדת החזירה שגיאה לכל קובצי התמונות: הממשק הציע פתיחה באתר המקור, בלי לטעון שהסריקה נכשלה. זה מוכיח את התנהגות הגיבוי; התמונות עצמן היו מדומות.

זה ממצא יעילות, ולא הוכחה שאובדות תמונות בגלל המכסה. עדיף בהמשך מטמון קצר לפי מזהה וקובץ וטעינת קובצי האתר לפני API, תוך שמירת רענון מדוד. אין צורך להוסיף שירות בתשלום או להפיץ סיסמאות.
